Taste, scored：原网页 Pre 讲解模式
版本：2026-11-22；原站基底 commit 826b13eb0c19e413987d040b2f5f3c6cd069a8c4。

这是什么
Pre 是原网站上的可选讲解层。原网页、图表、滚动叙事和控件继续使用同一份 DOM；没有独立的 Presentation HTML 页面，也不复制地图或图表。
旧的五页演示副本仅保留为历史方案，不作为这次的入口。

最新视觉与布局
旁白采用浅透明毛玻璃和深色文字，不使用深绿色背景。它不能遮住原网页内容。桌面演示会为独立讲解栏临时留出空间，原图表仍在原 DOM 中响应布局；收起后预留区域缩小。退出时移除临时布局样式，恢复普通页面。原 CSS、图表和数据文件没有为此被改写。
讲解栏不提供自由拖动或 Auto place；可用 Return to focus 返回当前图表讲解位置。
章节选择和 Previous/Next 合并在旁白框底部，没有独立工具栏、计时器、背景侧栏或左侧分割线。顶部 Hide 与收起后的 Show/Notes 保持原有方式。

如何使用
1. 使用 GitHub Pages 地址或本地 HTTP 服务打开原网站，不能只双击 HTML。
2. 普通打开时默认没有 Pre 控件。需要讲解时按 P，或在原网址加入 ?pre=1。
   示例：https://xiqixu.github.io/Taste-Scored/?pre=1#act-wheel
   上述线上地址只有在你把新版文件上传后才会具备新功能。
3. 用讲解层的上一步、下一步或节点选择切换讲解位置。显式切换才运行噪点溶解。
4. 正常滚动仍由原站驱动，旁白和引线随当前图表同步；前后滚动均不触发 Pre 转场。原控件仍可操作。
5. 按 H 收起/展开讲解面板。按 Escape 退出 Pre，继续正常阅读网站。
6. 汇报从风味轮附近开始；如果普通首页显示 espresso 片头，可使用原站 Skip intro。课堂讲解以图表操作为主，不播放视频代替汇报。

10 分钟讲解节点
wheel 70秒；scores 80秒；production 65秒；trade 65秒；altitude 60秒；cherry 45秒；processing 55秒；varieties 65秒；taste 60秒；team 35秒。
合计600秒，之后约3分钟Q&A。十个节点沿原站五幕与页尾credits展开，不是十个页面。
每张图的旁白合并解释其数据整理、视觉编码、实现工具和故事作用。工具不再独立成章；分工放在最后。
每个节点保留短正文和三个可切换焦点，一次只显示一条焦点说明。完整口述稿折叠在 Speaker notes 中。

文档对应
01_SPEAKER_SCRIPT_EN.txt：可直接口述的英文稿，与content.json的speakerNotes一致。
02_QA_EN.txt：备用问题与简短英文回答，不计入十分钟稿。
03_COURSE_COVERAGE_AND_DATA_NOTES.txt：课程五项覆盖、数据口径、来源和新版修正。
04_REHEARSAL_CUES_EN.txt：每个节点的时间和操作提示，不需要朗读。
05_VERSION_AND_REFERENCE_NOTES.txt：新旧方案区分、基底版本、参考素材与职责。

可调整的文案
pre-overlay/content.json 保存每个节点的标题、短说明、焦点、完整讲稿、建议秒数与来源。
只改speakerNotes后，记得同步英文稿。保持seconds合计600，summary不超过35个英文词，避免浮层占用过大。
sources中的本地数据链接按原网页目录解析，例如 data/cqi-2023.json。
